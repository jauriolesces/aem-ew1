# columns-video

Custom **columns** block. Purpose: video-stories.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 1 row, 2 cells: [h2, paragraph, CTA link] | [poster image + link to video /dam/Videos/fraud-stories.mp4, then 3 thumbnail images each linked to its video].

Once a video plays, a play/pause toggle appears in the player's top-right corner. Its accessible labels default to "Play video" / "Pause video"; localize them per page with the metadata keys `video-play-label` and `video-pause-label`.
